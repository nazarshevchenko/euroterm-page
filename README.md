# Євротерм-Тернопіль — сайт-візитка

Статичний сайт (HTML/CSS/JS) без бази даних. Заявки йдуть напряму в Telegram / Viber / дзвінок.

- `index.html` — головна
- `katalog.html` — каталог та сервіс котлів
- `montazh.html` — монтаж опалення
- `vodoochystka.html` — водоочистка та сіль PARLA
- `korysna-informatsiya.html` — калькулятори та поради
- `style.css` — базові стилі, `theme.css` — дизайн-шар, `script.js` — спільна логіка
- `img/` — фото та логотип
